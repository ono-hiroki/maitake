# Istio でサービスメッシュを構築する

Istio は、マイクロサービス間の通信を管理するサービスメッシュの実装です。Envoy プロキシをデータプレーンとして使用し、トラフィック管理、セキュリティ、オブザーバビリティを提供します。

> **Note**: 本ガイドでは `kubectl` のエイリアスとして `k` を使用しています。

---

## サービスメッシュの必要性

マイクロサービスアーキテクチャでは、各サービスでリトライ/タイムアウト、サーキットブレーカー、認証/認可、ログ/メトリクス、トレーシングなどの実装が必要になります。これらを個別に実装するとコードの重複、言語ごとに異なる実装、設定の一貫性の欠如といった問題が生じます。

Istio はこれらの機能をインフラ層で提供します。

```
┌──────────────────────────────────────────────────────────────┐
│  Istio Service Mesh                                          │
│                                                              │
│  ┌─────────────────┐  ┌─────────────────┐  ┌──────────────┐ │
│  │ Pod A           │  │ Pod B           │  │ Pod C        │ │
│  │ ┌─────┐ ┌─────┐ │  │ ┌─────┐ ┌─────┐ │  │ ┌─────┐┌───┐│ │
│  │ │App A│←│Envoy│←┼──┼→│Envoy│→│App B│ │──┼→│Envoy││App││ │
│  │ └─────┘ └─────┘ │  │ └─────┘ └─────┘ │  │ └─────┘└───┘│ │
│  └─────────────────┘  └─────────────────┘  └──────────────┘ │
│           ▲                   ▲                   ▲         │
│           └───────────────────┼───────────────────┘         │
│                               │                             │
│                        ┌──────┴──────┐                      │
│                        │   istiod    │ ← Control Plane      │
│                        │ (Pilot等)   │                      │
│                        └─────────────┘                      │
└──────────────────────────────────────────────────────────────┘
```

## アーキテクチャ

| コンポーネント | 役割 |
|--------------|------|
| **istiod** | Control Plane の統合コンポーネント |
| ├ Pilot | Envoy への設定配布（xDS API） |
| ├ Citadel | 証明書の発行・管理（mTLS） |
| └ Galley | 設定の検証・変換 |
| **Envoy Sidecar** | 各 Pod に注入されるプロキシ |
| **Ingress Gateway** | 外部トラフィックの入口 |
| **Egress Gateway** | 外部サービスへの出口 |

## 主要な CRD

| CRD | 役割 | Envoy 設定との対応 |
|-----|------|------------------|
| **VirtualService** | ルーティングルール | Route |
| **DestinationRule** | トラフィックポリシー | Cluster |
| **Gateway** | 外部トラフィックの入口 | Listener |
| **ServiceEntry** | 外部サービスの登録 | Cluster |

## セットアップ

```bash
# istioctl のインストール
curl -L https://istio.io/downloadIstio | sh -
cd istio-*
export PATH=$PWD/bin:$PATH

# demo プロファイルでインストール（学習用）
istioctl install --set profile=demo -y

# インストール確認
k get pods -n istio-system
```

## Istio vs アプリケーション実装

| 項目 | Istio | アプリケーション実装 |
|------|-------|---------------------|
| **導入コスト** | 設定のみ | コード変更必要 |
| **言語非依存** | Yes | 言語ごとに実装 |
| **リトライ** | 基本的な設定 | 柔軟な Backoff 戦略 |
| **サーキットブレーカー** | Pod 単位の除外 | サービス全体の遮断 |
| **オブザーバビリティ** | 自動収集 | 個別実装 |
| **リソース消費** | サイドカー分のオーバーヘッド | なし |

推奨アプローチ: Istio でインフラ層の基本機能（リトライ、mTLS、メトリクス）を担い、アプリケーション層でビジネスロジック連携のリトライやサービス全体のサーキットブレーカーを実装する。
