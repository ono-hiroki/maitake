# Capstone: EKS で本格的な Kubernetes 環境を構築する

このリポジトリで学んだ知識を活かして、AWS EKS 上に本格的な Kubernetes 環境を構築するプロジェクトです。

## 学習内容

- Terraform による EKS クラスタ構築
- Kustomize リモートベースによるマニフェスト管理
- Argo CD による GitOps デプロイ
- Istio サービスメッシュ
- External Secrets / External DNS
